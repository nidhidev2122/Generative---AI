## 🔐 API Key Safety

- Keep API keys in environment variables.
- Do not commit secrets or `.env` files.
- Use a `.env.example` file with placeholder values when needed.

1. Clone the repository.
2. Install the dependencies required by the experiment.
3. Configure any necessary API keys locally.
4. Follow the instructions in each notebook or script.
